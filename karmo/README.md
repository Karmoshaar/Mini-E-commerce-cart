# 🎵 Karmo — بوت موسيقى ديسكورد

**Karmo** بوت بشغّل موسيقى بروم الصوت وإنتو عم تلعبو. بتحطلو **أي رابط** وهو بشغّلو، ولما تخلص الأغاني **بكمّل لحالو بأغاني من نفس النمط**.

- 🔗 **أي مصدر**: YouTube، YouTube Music، SoundCloud، Spotify، Deezer، Apple Music، أنغامي، Bandcamp، Twitch، TikTok، Vimeo، Mixcloud، ملفات mp3 مرفوعة، وأكثر من 1000 موقع (عن طريق [yt-dlp](https://github.com/yt-dlp/yt-dlp)). بلاي ليستات وألبومات كمان.
- 📻 **تشغيل تلقائي**: لما تخلص القائمة بجيب أغنية مشابهة من "Mix" يوتيوب للأغنية اللي خلصت (نفس الطريقة اللي يوتيوب بيقلب فيها). ما بكرر أغاني اشتغلت قبل، وما بجيب نفس الأغنية بنسخة ثانية (Lyrics/Remix...). وإذا تخطيت أغنية بسرعة، ما ببني عليها الاختيار الجاي.
- ⚡ **أوامر قصيرة**: `!p` `!s` `!q`... + أوامر سلاش `/p` `/s`... + **أزرار** تحت رسالة "يشتغل الآن" (إيقاف، تخطي، رجوع، تكرار، تلقائي، صوت).
- 🎮 **مناسب للعب**: إذا طلع الكل من الروم بوقّف مؤقتاً وبيرجع يكمّل لما حدا يفوت، وبيطلع لحالو إذا ضل فاضي.

---

## 1) جهّز البوت على ديسكورد (مرة وحدة، 3 دقايق)

1. افتح [Discord Developer Portal](https://discord.com/developers/applications) واضغط **New Application** وسمّيه **Karmo**. (حتى لو سمّيته غير شي، البوت بيغيّر اسمو لـ Karmo لحالو أول ما يشتغل.)
2. من القائمة اليسار ادخل **Bot**:
   - اضغط **Reset Token** وانسخ التوكن (لا تعطيه لحدا! اللي معو التوكن بيتحكم بالبوت).
   - تحت **Privileged Gateway Intents** فعّل **Message Content Intent** واحفظ (هاد ضروري للأوامر اللي بتبلش بـ `!`).
3. شغّل البوت (الخطوة 2 تحت). أول ما يشتغل بيطبعلك **Invite link** — افتحو واختار سيرفرك.

## 2) التشغيل

بدك **Node.js 22.12 أو أحدث** — نزّل نسخة LTS من [nodejs.org](https://nodejs.org). ما بدك تنزّل ffmpeg ولا yt-dlp، البوت بيجيبهم لحالو.

### ويندوز
1. دبل كليك على **`start.bat`**.
2. أول مرة رح يفتحلك ملف `.env` — الصق التوكن بعد `DISCORD_TOKEN=` واحفظ وسكّر.
3. دبل كليك على `start.bat` مرة ثانية. خلص! 🎉 (إذا وقف البوت لأي سبب، الملف بيرجّعو يشتغل لحالو.)

### لينكس / ماك
```bash
cp .env.example .env     # وحط التوكن جوا
./start.sh               # أو: npm install && npm start
```

> خلّي الشباك مفتوح طول ما بدك البوت شغال. إذا بدك ياه شغال 24/7 لازم يضل جهاز شغال (كمبيوترك أو سيرفر). على سيرفرات الاستضافة يوتيوب أحياناً بيطلب تسجيل دخول — شوف قسم المشاكل تحت.

## الأوامر

كل أمر إلو **حرف واحد** بالإنجليزي، و**كلمة عربية** (وبعضهم حرف عربي كمان). اكتب `!` وبعدها الأمر.
البوت بيفهم العربي بأكثر من كتابة: `اطفى` = `اطفي`، `شغّل` = `شغل`، `قايمة` = `قائمة`.
البادئة `!` بتتغير من `.env`، وفيك تكتب `@Karmo ش اسم الأغنية` بدلها. أوامر السلاش هي نفس الحرف: `/p`، `/s`، `/x`...

| الحرف | بالعربي | شو بيعمل |
|---|---|---|
| `!p` | `!ش` `!شغل` | شغّل أي رابط أو اسم أغنية أو ملف مرفق. مثال: `!ش فيروز كيفك انت` |
| `!t` | `!بعدها` | متل التشغيل، بس الأغنية بتشتغل **بعد الحالية** مباشرة |
| `!s` | `!ت` `!تخطي` | تخطّى (`!s 3` بيتخطى 3 أغاني) |
| `!b` | `!ر` `!رجع` | رجّع الأغنية اللي قبل |
| `!w` | `!استنى` | إيقاف مؤقت / كمّل (نفس الأمر) |
| `!r` | `!ك` `!كمل` | كمّل |
| `!x` | `!ط` `!اطفي` `!وقف` | وقّف التشغيل وفضّي القائمة |
| `!i` | `!شو` | شو عم يشتغل هلق مع شريط الوقت |
| `!q` | `!ق` `!قائمة` | القائمة (`!q 2` الصفحة الثانية) |
| `!a` | `!تلقائي` | شغّل/طفّي **التشغيل التلقائي** لأغاني من نفس النمط |
| `!l` | `!كرر` | التكرار: مطفي ← الأغنية ← القائمة |
| `!v` | `!ص` `!صوت` | الصوت: `!v 50` (من 0 لـ 200) |
| `!m` | `!خ` `!خلط` | اخلط القائمة |
| `!d` | `!شيل` | شيل أغنية من القائمة برقمها: `!d 3` |
| `!c` | `!فضي` | فضّي القائمة (الحالية بتكمّل) |
| `!g` | `!قدم` | روح لوقت بالأغنية: `!g 1:30` |
| `!j` | `!فوت` | فوت على رومك الصوتي |
| `!e` | `!اطلع` | اطلع من الروم |
| `!h` | `!مساعدة` | كل الأوامر |

**الأزرار** تحت رسالة "يشتغل الآن": ⏮️ رجوع • ⏸️ إيقاف/كمّل • ⏭️ تخطي • ⏹️ وقّف • 📜 القائمة • 🔁 تكرار • 📻 تلقائي • 🔀 خلط • 🔉🔊 الصوت.

## الإعدادات (`.env`)

| المتغير | الافتراضي | شو هو |
|---|---|---|
| `DISCORD_TOKEN` | — | توكن البوت (مطلوب) |
| `BOT_NAME` | `Karmo` | اسم البوت، بيغيّر اسمو لحالو عند التشغيل (ديسكورد بيسمح بتغييرين بالساعة) |
| `PREFIX` | `!` | بادئة الأوامر |
| `AUTOPLAY` | `true` | التشغيل التلقائي شغال من البداية |
| `DEFAULT_VOLUME` | `80` | الصوت الافتراضي |
| `IDLE_TIMEOUT_SECONDS` | `180` | بعد قديش يطلع إذا ما في شي يشتغل / ما في حدا |
| `GUILD_ID` | — | آيدي سيرفرك ليظهر أوامر `/` فوراً |
| `MAX_QUEUE` / `MAX_PLAYLIST` | `500` / `200` | حدود القائمة والبلاي ليست |
| `YTDLP_COOKIES` | — | ملف cookies.txt (شوف تحت) |
| `YTDLP_COOKIES_FROM_BROWSER` | — | `firefox` أو `chrome`... |

## مشاكل وحلول

- **أوامر `!` ما بترد بس `/p` شغالة** → ما فعّلت **Message Content Intent** (الخطوة 1). البوت بيكتب تحذير بالشاشة بهالحالة.
- **البوت ما بيفوت عالروم** → تأكد إنو عندو صلاحيات **Connect** و **Speak** بالروم.
- **يوتيوب بيقول "Sign in to confirm you're not a bot"** → بيصير غالباً على سيرفرات الاستضافة مش على كمبيوترك. الحل: حط `YTDLP_COOKIES_FROM_BROWSER=firefox` (لازم تكون فاتح يوتيوب بفايرفوكس بحساب)، أو صدّر ملف `cookies.txt` بإضافة "Get cookies.txt LOCALLY" وحط `YTDLP_COOKIES=cookies.txt`. (كروم على ويندوز صار يمنع قراءة الكوكيز، فايرفوكس أضمن.) استعمل حساب ثانوي مش حسابك الأساسي.
- **موقع معيّن بطّل يشتغل** → البوت بيحدّث yt-dlp لحالو كل يوم. إذا مستعجل: سكّر البوت وامسح مجلد `bin` وشغّلو، بينزّل آخر نسخة.
- **سبوتيفاي/ديزر/آبل ميوزك**: هالمواقع ما بتسمح بتشغيل الصوت مباشرة، فالبوت بيقرأ اسم الأغنية والفنان وبيشغّلها من يوتيوب. البلاي ليست لازم تكون **Public**.
- بدك تشوف تفاصيل أكثر بالأخطاء؟ حط `DEBUG=true` بـ `.env`.
